## 0. 一句话结论

Open Diff **不是** Beyond Compare 5 的 1:1 复刻，也不是计划文档所宣称的「全阶段已完成」产品。  
当前是一个 **Workbench 风格的桌面对比应用**：文本 / 本地文件夹 / CSV / hex / 图片统计 / `.reg` / 媒体标签 有真实闭环；三方文本合并、远程 VFS、归档、报告/脚本、Git/SVN 产品化仍是骨架或未接线。

`docs/小时级开发任务计划.md` 把 S0–S12 与 X-01–X-10 **全部标成已完成，不可信。**  
README 自己写了 “early repository stage”，比计划诚实。

## 3. 分领域完成度

判定：

- **完成**：主路径端到端可用，不是演示数据主导。
- **部分完成**：有真实后端或 API，但 UI 缺能力、有假数据/假按钮，或库比产品面宽。
- **仅骨架**：有路由/crate/类型，核心行为硬编码或 Memory mock。
- **未做**：无产品入口或无真实实现。

### 3.1 Text Compare — 部分完成

**证据**

- 路由：`/compare/text` → `src/views/TextCompareView.vue`
- Tauri：`diff_text`、`read_text_file`、`parse_text_patch`
- 算法：`diff-core` 实现 Myers / Patience / Histogram、行内字符差、忽略空白/大小写/行尾/正则、补丁解析（crate 测试 13 通过）
- UI：读文件、跑 diff、差异导航、查找替换、书签、HTML 预览、左右复制当前差异、算法选择

**缺口**

- 打开视图先显示硬编码示例 diff。
- 前端 **没有** 把 `ignoreWhitespace` / `ignoreCase` / `ignoreLineEndings` / `ignoreRegexes` 传给 `diff_text`（后端有，UI 无）。
- README 写的语法高亮、忽略注释、编码选择：`format-core` 有 grammar matcher，Text Compare 未形成完整高亮/重要性 UI。
- 无 BC5 级 Session Settings、报告、Swap/Reload/Section 语义。

### 3.2 Folder Compare / Sync / Merge — 部分完成

**Folder Compare**

- 路由：`/compare/folder`
- Tauri：`compare_folder_paths`（本地递归扫描 + 对齐 + 同名文件二进制比较）
- `folder-core` 体量大（约 1700+ 行），含 CRC/二进制比较、过滤模型、报告 HTML/XML/文本渲染。
- `ui` 合入后：Copy / Rename / Delete / Attributes / Touch 有确认并调 Tauri。

缺口（2026-09-06 复核）：初始演示树与假路径已清除，未比较前为空态；Copy / Move / Rename / Delete / Attributes / Touch 经 Tauri 真实落盘，失败会显示错误；Open / Compare To / Quick Compare 会打开子比较会话；Open With 调外部程序。仍缺：Align With / Break Alignment（按钮已禁用）、远程/归档一侧、对齐覆盖持久化。

**Folder Sync**

- 路由：`/sync/folder`
- `preview_folder_sync` + `execute_folder_sync` 真实存在。
- 策略：updateRight / updateLeft / updateBoth / mirrorRight / mirrorLeft。

缺口：无逐项 Leave/反向复制/删除覆盖；无 Accept/Cancel 工作流；默认路径是占位符。BC5 审计「无执行」对 **当前 master 已不成立**。

**Folder Merge**

- 路由：`/merge/folder`
- `build_folder_merge_plan` + `execute_folder_merge_plan`。
- `folder-merge-core` 做结构计划（Keep / CopyLeft / CopyRight / Delete / MarkConflict）。

缺口：冲突点进 `/merge/text` **不传路径**；合并是路径级复制/删除，不是文件内容三方合并。

### 3.3 Table — 部分完成

**证据**

- 路由：`/compare/table`
- Tauri **只有** `compare_table_csv`（字符串 CSV，固定第一列对齐）。
- `table-core` 库内另有 TSV、自定义分隔符、HTML table、**calamine 读 Excel**、sheet/列映射、关键列/排序对齐、数值/日期容差、报告模型。

**缺口**

- 产品面未暴露 Excel / HTML / TSV / 分隔符 / 关键列参数。
- 前端手动列映射、忽略列 **不传后端**。
- README「TSV / spreadsheet / 分隔符」对当前 UI **过声称**。

### 3.4 Hex — 部分完成

**证据**

- 路由：`/compare/hex`
- Tauri：`compare_hex_files`
- `hex-core` 有分块读、差异扫描、窗口、查找/替换、按字节保存。

**缺口**

- 前端固定 `offset: 0, length: 256`，无全文件浏览/跳转。
- Tauri 用 `fs::read` **整文件载入**，与 crate「按块读」能力不一致。
- 查找/替换/保存未接到 UI。
- （2026-09-06）初始空态，不再显示 A–Z 演示字节。

### 3.5 Image — 部分完成

**证据**

- 路由：`/compare/picture`
- Tauri：`compare_picture_files`（PNG/JPEG/WebP 解码 + 同尺寸像素差 + 元数据行）
- `image-core` 另有 RGB 容差、Alpha、替换色忽略。

**缺口**

- **不渲染真实图片**：`.picture-image` 是 CSS 渐变占位，不是 `<img>` / canvas。
- Tauri 未传容差选项。
- overlay 是视觉层，与后端 bounding rect 未完整联动。
- README Planned 的「tolerance / visual overlay」仍缺。

### 3.6 三方文本合并 — 仅骨架

**证据**

- 路由：`/merge/text` → `TextMergeView.vue`
- 冲突、四窗格内容 **全部硬编码**；`acceptConflict` 写成固定三行。
- 只调用 `saveTextFile`。
- `merge-core` 是 **按行索引** 的三路合并（非 Myers 式 diff3）；CLI `merge-text --automerge` 会用它，**UI 不用**。

README Core Features 写 “designed to support” — 对 UI 而言就是未完成。  
`sessionCatalog` 却标 `implemented: true`。

### 3.7 Sessions — 部分完成

**证据**

- 首页、标签、`savedSessions` / workspace store、拖放识别、自动选视图、导入导出 JSON、锁定字段。
- `session-core` 有 named / auto-saved / shared / workspace 的 JSON 持久化。
- CLI `open-session` 只 load 并打印。

**缺口**

- 会话目录 **15 项全 `implemented: true`**，与真实完成度不符。
- Home 历史、工作区总数（如 `142`）有硬编码。
- File Format 规则不参与打开路由。
- 共享会话 / 企业策略未接到桌面主路径。

### 3.8 Reports / CLI / Scripts — 仅骨架（产品面）

**证据**

- `report-core`：给定 `UnifiedReport` 可渲染 HTML/文本/JSON/XML。
- `folder-core` 自带文件夹报告渲染。
- `script-core`：能解析 LOAD/FILTER/COMPARE/REPORT/LOG 等，执行需注入 engine；测试用 mock。
- 二进制：`open-diff-cli` — `compare`、`compare-folders`、`open-session`、`merge-text --automerge`、打印 git/svn 配置。
- UI：`/reports/scripts` 的 jobs / scriptLines 是静态常量，按钮无真实执行。

**缺口**

- Tauri **没有** 报告/脚本 command。
- `shell-compare` 只 `println!`。
- 无 BC 兼容 `/fv`、`/sync`。
- README Automation 标 planned — 与产品面一致。

### 3.9 Remote / VFS — 仅骨架 / 本地完成

**VFS**

- `vfs-core::LocalVfs` 真实（list/read/write/backup/delete）。
- **没有** 远程 / 归档 provider 实现接到比较路径。

**Remote**

- `remote-core` 约 1800 行，协议枚举齐：FTP/FTPS/SFTP/WebDAV/S3/Dropbox/OneDrive/SVN。
- 实现全是 `Memory*Provider` + `BTreeMap`，**零网络依赖**。
- 测试 31 通过，测的是内存假 provider。
- UI `/settings/remote-profiles`：前端内存 CRUD；`testProfileConnection` 只把状态设为 queued。
- **无 Tauri command。**

这就是「crate 很大、类型很全、仍是仅骨架」的典型。

### 3.10 Archives / Snapshot — 仅骨架 / 未做（产品面）

- `snapshot-core`：对预扫描条目做 JSON 快照与比较，不扫盘。无 Tauri / UI。

### 3.11 Git / SVN — 未做（产品面） / 部分完成（配置生成）
